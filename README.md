# Sherlock-Model

## Core Information
- Sherlock model is Deep Learning Model made by Michal Pospisil, Matous Rubek and Stepan Dupac.
- Sherlock can recognize handwritten number on image.
- This model is 100% open-source and everyone can use it for their tasks, goals and learning.

## How to Use it
1. Clone this GitHub repo to your personal computer
2. When you have downloaded it - You have to also have: Python 3.12 and every libary, which is used.
3. First Task is to pre-train this model - start file train.py in src folder
4. Finally you can start file app.py, also in src folder and Enjoy it!!
